# Система управления личными финансами

Консольное приложение на Java для учёта доходов, расходов и бюджетов по категориям.

## Сборка и запуск

Нужны JDK 21 и Apache Maven 3.9.

```powershell
mvn verify
java -jar target/personal-finance.jar
```

На первом этапе приложение выводит название проекта. Финансовые операции будут добавлены по мере реализации.
